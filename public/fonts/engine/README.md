# Existing AI engine fonts

Unmodified WOFF2 assets previously self-hosted by next/font/google in the successful production build. The accompanying CSS preserves all weights, unicode ranges, fallback metrics and CSS variable names. Bundling them avoids build-time network/font-loader failures without changing the type system. The supplied website mockup fonts and Korean Pretendard styling are unchanged.

Upstream licenses: https://github.com/google/fonts/tree/main/ofl/spacegrotesk, https://github.com/google/fonts/tree/main/ofl/inter, https://github.com/google/fonts/tree/main/ofl/ibmplexmono. See the three OFL files here.
